How it works
  • A headless Chromium browser opens the Codolio page and intercepts the internal API calls.
  • Each question is upserted — existing questions have their companies and topics merged in.
  • New questions get a sequential questionId and are immediately visible in /sheet/<slug>.
  • Requires: pip install playwright beautifulsoup4 && playwright install chromium
