Given an array (or string), the task is to reverse the array/string.

### Example 1:
**Input:** `arr = [1, 2, 3, 4, 5]`
**Output:** `[5, 4, 3, 2, 1]`

### Example 2:
**Input:** `arr = [4, 5, 1, 2]`
**Output:** `[2, 1, 5, 4]`

### Constraints:
*   `1 <= arr.length <= 10^5`
*   `-10^9 <= arr[i] <= 10^9`
